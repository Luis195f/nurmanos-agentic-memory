# NurManOS Agentic Memory

Public hackathon repository for a newly built agentic-memory application using
CockroachDB as its persistent memory layer and AWS as its deployment platform.

## Current status

H0 runtime and eligibility proof only. Product implementation has not started.
No external dependency is claimed as working until sanitized runtime evidence
has been captured against the real service.

## Safety boundary

Only synthetic demonstration data may be used. Do not add real patient,
employee, hospital, unit, protocol, incident-report, or institutional-document
data. Never commit credentials or unsanitized service output.

## Development runtime

- Node.js 22.14.0
- pnpm 10.15.0

The application architecture and setup instructions will be added only after
the H0 GO/NO-GO decision.
