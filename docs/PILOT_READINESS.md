# Pilot readiness

v0.1.0 is a public synthetic-data technical demonstration. It is not ready for a
healthcare pilot, production care environment, medical-device claim, or clinical
decision-making.

## Demonstration-ready capabilities

- Bounded autonomous store/retrieve tool flow with typed contracts.
- Persistent vector memory isolated by an anonymous synthetic workspace.
- TLS, parameterized SQL, strict synthetic metadata, generic errors, bounded cost,
  least-privilege runtime IAM, sanitized observability, CI, and operational docs.
- Responsive bilingual UI with keyboard, reduced-motion, and optional evidence view.

## Mandatory gates before a real pilot

- Named service owner, controller/processor roles, DPO and legal review, DPIA, lawful
  basis, data-flow inventory, retention/deletion policy, and incident process.
- Clinical governance and explicit validation that the product remains organizational
  support, with claims, intended use, human oversight, and safety case approved.
- Enterprise SSO, tenant model, RBAC/ABAC, privileged administration, joiner/mover/
  leaver flow, session revocation, and immutable audit trails.
- Institutional threat modeling, independent pentest, secure SDLC, signed releases,
  SBOM, dependency response, WAF, DLP, key rotation, backup/restore exercises, DR,
  monitoring ownership, on-call runbooks, and availability/cost targets.
- Formal accessibility, privacy, security, performance, usability, and model-quality
  validation with approved synthetic datasets before any controlled real-data study.

No real or pseudonymized healthcare/personnel data may be introduced merely because
the public demo works.
