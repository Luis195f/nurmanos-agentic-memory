# Roadmap

## After v0.1.0

1. Add authenticated server-side workspaces with SSO, tenant authorization, RBAC,
   short-lived sessions, revocation, and per-user quotas.
2. Add a governed deletion/retention lifecycle, administrative audit trail, backup
   restore drill, and user-visible workspace reset.
3. Add WAF/rate policies, cost anomaly notifications, an approved Budget recipient,
   load testing, and per-operation service-level objectives.
4. Expand adversarial evaluation for prompt injection, identifier leakage, tool
   schema drift, retrieval grounding, cross-namespace access, and model upgrades.
5. Complete institutional DPIA, DPO/legal/clinical governance, threat-model review,
   pentest, vendor/security assessment, accessibility audit, and pilot validation.

Feature expansion into clinical workflows is explicitly deferred until these safety,
identity, governance, and operational foundations are approved.
